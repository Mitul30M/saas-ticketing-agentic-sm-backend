# Troubleshooting a delayed sync

Check the integration connection, the last successful sync time, and whether the provider reports an outage. Reconnect only after recording the error and confirming that the correct workspace is selected.

If the sync is still delayed, provide the integration name, affected object type, and approximate start time.
