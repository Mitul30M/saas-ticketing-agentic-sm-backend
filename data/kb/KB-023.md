# Nimbus webhooks and event delivery

Webhook consumers should verify the signature, return a quick 2xx response, and process events asynchronously. Store the event ID so retries are idempotent. Nimbus may retry a delivery when the endpoint times out or returns an error.

Use the event ID and delivery timestamp when asking support to investigate a missing event.
