# Upgrading a Nimbus plan

A workspace admin can request an upgrade from **Settings → Billing → Change plan**. Review the target plan's features, seat limits, billing cycle, and any prorated charge before confirming.

## Request steps

1. Open the billing settings and select the target plan.
2. Review the current plan, target plan, effective date, and estimated invoice change.
3. Confirm that the requester is an authorized workspace admin.
4. Submit the request with the target plan and whether it should start now or next cycle.

An upgrade proposal must identify the current and target plans and its effective date. The displayed estimate is not proof of a final charge; the resulting invoice is authoritative.

## Approval

An upgrade proposal remains `pending_approval` until an authorized human approves it. The agent may prepare evidence, but it cannot change the subscription or call the executor directly.
