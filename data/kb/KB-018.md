# Configuring single sign-on

Business workspaces can configure SSO from **Settings → Security → Single sign-on**. Only a workspace administrator should change the configuration. Keep a verified admin login available while testing so a configuration error does not lock out the workspace.

## Setup steps

1. Copy the Nimbus ACS URL and entity ID into the identity provider.
2. Configure the provider's metadata URL or XML document in Nimbus.
3. Map the stable email claim to the Nimbus user email.
4. Save the configuration and test with one administrator account.
5. Confirm that the returned email and workspace match before enabling enforcement.

Use the provider's exact signing certificate and keep its rotation date documented. A mismatch in metadata, audience, issuer, or email claim commonly causes a login failure.

## Recovery

Do not enable “require SSO” until the test succeeds. If users are locked out, use the verified admin session or the documented recovery administrator. Never send identity-provider secrets or assertion contents in a ticket.
