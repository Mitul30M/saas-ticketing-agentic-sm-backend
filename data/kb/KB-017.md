# Resetting a Nimbus password

Use the password-reset flow when a user cannot sign in. The reset email is sent only to the address already associated with the Nimbus account. Support will never ask for the current password or a one-time code.

## Reset steps

1. Open the Nimbus sign-in page and select **Forgot password**.
2. Enter the account email and submit the form once.
3. Open the newest reset email and follow its link.
4. Choose a new password that is not reused elsewhere, then sign in again.

The link expires for security. If it does not arrive after a few minutes, check spam, corporate mail filtering, and whether the address is correct. Repeating the request invalidates older links.

## If the reset still fails

Do not send a password or reset link to support. Ask an authorized workspace administrator to verify the account address. If the account uses SSO, use the identity provider's recovery process instead of repeatedly requesting a Nimbus password reset.
