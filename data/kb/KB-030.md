# Nimbus service interruption checklist

For a suspected interruption, check the status page, test a second workspace member, and capture the request timestamp and error code. Do not repeatedly submit a write request while the service is degraded.

This checklist helps collect evidence; it does not promise a resolution time or replace an incident response.
