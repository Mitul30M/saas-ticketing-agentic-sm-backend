# Nimbus API rate limits

API responses include rate-limit information. When a client receives HTTP 429, honor the Retry-After value and use exponential backoff with jitter. Avoid retrying non-idempotent requests blindly.

If limits are reached consistently, provide the endpoint, request volume, and timestamps without sharing credentials.
