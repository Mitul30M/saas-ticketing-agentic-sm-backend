# Checking refund status

A refund request can be pending approval, approved, rejected, executed, or failed. Pending approval means no payment data has been changed. Approved means a human accepted the proposal; execution is a separate deterministic step.

Ask support for the ticket or refund request reference rather than submitting a second request for the same invoice.
