# Creating and rotating Nimbus API keys

Workspace admins create API keys from Settings, Developer, and API keys. Give each integration its own key, store it in a secret manager, and rotate it if exposure is suspected.

API keys are secrets. Never paste a key into a support ticket or commit it to source control.
