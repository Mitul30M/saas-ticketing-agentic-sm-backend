# Creating and rotating Nimbus API keys

Workspace admins create API keys from **Settings → Developer → API keys**. Give each integration its own key, assign the narrowest available scopes, and store it in a secret manager. A key is shown only when it is created, so save it before leaving the page.

## Rotation steps

1. Create a replacement key with the same or narrower scopes.
2. Deploy it to the integration's secret store.
3. Confirm requests succeed with the replacement.
4. Revoke the old key and record the rotation time.

If exposure is suspected, revoke first, then investigate access logs and create a replacement. Do not wait for a scheduled rotation after a leak.

## Secret handling

API keys are secrets. Never paste a key into a support ticket, browser console, source file, or commit. When reporting an API problem, provide the workspace, endpoint, status code, and timestamp with the key redacted.
