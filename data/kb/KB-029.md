# Checking Nimbus service availability

Check the Nimbus status page for an active incident before retrying requests. Record the status-page incident ID, affected feature, and first observed time.

If the status page is clear, retry once after checking local network access and browser console errors. A widespread or unresolved outage requires human investigation.
